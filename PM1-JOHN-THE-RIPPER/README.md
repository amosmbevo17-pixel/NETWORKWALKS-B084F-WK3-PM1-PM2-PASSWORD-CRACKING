# W3-PM1 — Password Cracking with John the Ripper

## 1. Introduction

This practical exercise focused on recovering the password of a protected PDF using John the Ripper through its graphical interface, Johnny.

The exercise was performed on a Windows laptop.

## 2. Tools Used

- Windows
- Johnny GUI
- John the Ripper
- Online Hash Crack PDF Hash Extractor

## 3. Methodology

### Step 1: Extracting the PDF Hash

The password-protected PDF was processed using the Online Hash Crack PDF Hash Extractor.

Tool: https://www.onlinehashcrack.com/tools-pdf-hash-extractor.php

The extracted hash was obtained for use during the password-cracking exercise.

### Step 2: Loading the Hash into Johnny

Johnny was launched on Windows and the extracted PDF hash was loaded into the application.

### Step 3: Password Cracking

The loaded hash was processed through Johnny/John the Ripper.

The application displayed a successfully recovered password.

The exact attack mode and wordlist were not confirmed.

### Step 4: Password Verification

The recovered password was entered into the original PDF document.

The PDF opened successfully, confirming the recovery result.
