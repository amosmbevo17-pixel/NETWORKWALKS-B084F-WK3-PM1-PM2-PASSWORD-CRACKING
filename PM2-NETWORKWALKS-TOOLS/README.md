# W3-PM2 — Password Cracking with Networkwalks Tools

## 1. Introduction

This practical exercise involved recovering the password of an encrypted PDF using the Networkwalks Hash Calculator and Password Cracker.

The exercise was performed on Windows using Google Chrome.

## 2. Tools Used

- Windows
- Google Chrome
- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- PDF Reader

## 4. Methodology

### Step 1: Downloading the Encrypted PDF

Downloaded the supplied `My Locked PDF1.pdf` training file from the Networkwalks lab page.

### Step 2: Hash Extraction

Opened the Networkwalks Hash Calculator and uploaded the encrypted PDF.

The tool generated a PDF password hash beginning with `$pdf$`.

### Step 3: Copying the Hash

Copied the complete extracted hash for submission to the password-cracking tool.

### Step 4: Password Cracking

Opened the Networkwalks Password Cracker and pasted the extracted hash.

Started the attack and waited for the tool to process the hash.

### Step 5: Password Recovery

The tool successfully recovered the PDF password.

### Step 6: PDF Verification

Opened the original PDF and entered the recovered password.

The document opened successfully.

### Step 7: Flag Capture

The PDF displayed the Networkwalks congratulations message confirming successful flag capture.
